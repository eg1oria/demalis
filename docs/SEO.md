# SEO и аналитика: что сделать владельцу проекта (Этап 6)

Всё ниже — после того как сайт выложен на Vercel и у него есть постоянный адрес (лучше свой домен).
Сначала впиши адрес сайта в `NEXT_PUBLIC_SITE_URL` (Vercel → Settings → Environment Variables), например `https://demalys.kz`, и сделай Redeploy. От него строятся канонические ссылки, `sitemap.xml` и ссылки для соцсетей.

Проверь, что открываются:

- `https://<сайт>/sitemap.xml` — список всех страниц (главная, каталог, подборки, объекты) на двух языках;
- `https://<сайт>/robots.txt` — там должна быть строка `Sitemap: https://<сайт>/sitemap.xml`.

---

## 1. Яндекс Метрика

1. Открой [metrika.yandex.ru](https://metrika.yandex.ru) → «Добавить счётчик».
2. Адрес сайта — твой домен. Галочку «Вебвизор» **не ставь**: он записывает ввод в формах, а там телефоны гостей.
3. После создания Метрика покажет номер счётчика (8–9 цифр). Код вставлять не нужно — только номер.
4. Впиши его в `NEXT_PUBLIC_YANDEX_METRIKA_ID` в Vercel и сделай Redeploy.
5. Открой сайт, походи по страницам. Через несколько минут в Метрике → «Отчёты» → «Посещаемость» появятся визиты.

Счётчик грузится после того, как страница показана, и не замедляет сайт. Переходы по страницам внутри сайта тоже считаются. Админка не отслеживается.

## 2. Яндекс Вебмастер

1. Открой [webmaster.yandex.ru](https://webmaster.yandex.ru) → «Добавить сайт» → введи адрес.
2. Способ подтверждения — **«Мета-тег»**. Яндекс покажет строку вида
   `<meta name="yandex-verification" content="1234abcd5678efgh" />`.
   Скопируй только значение `content` (`1234abcd5678efgh`).
3. Впиши его в Vercel в переменную `YANDEX_VERIFICATION`, сделай Redeploy и нажми в Вебмастере «Проверить».
4. После подтверждения: «Индексирование» → «Файлы Sitemap» → добавь `https://<сайт>/sitemap.xml`.
5. «Настройки индексирования» → «Региональность»: укажи Алматы.

## 3. Google Search Console

1. Открой [search.google.com/search-console](https://search.google.com/search-console) → «Добавить ресурс» → **«Ресурс с префиксом в URL»** → введи адрес сайта.
2. Способ подтверждения — **«Тег HTML»**. Google покажет
   `<meta name="google-site-verification" content="AbCd...xyz" />`.
   Скопируй значение `content`.
3. Впиши его в Vercel в переменную `GOOGLE_SITE_VERIFICATION`, сделай Redeploy и нажми «Подтвердить».
4. «Файлы Sitemap» → введи `sitemap.xml` → «Отправить».

Первые страницы появятся в поиске через несколько дней — это нормально.

## 4. Проверка структурированных данных

На странице объекта есть разметка `LodgingBusiness` (место отдыха: адрес, координаты, цена, удобства) и `BreadcrumbList` (хлебные крошки). На странице подборки — `BreadcrumbList`.

1. Открой [search.google.com/test/rich-results](https://search.google.com/test/rich-results).
2. Вставь адрес любой страницы объекта, например `https://<сайт>/ru/place/<slug>`.
3. Должно быть «Страница пригодна для расширенных результатов» или список найденных элементов **без ошибок** (предупреждения о необязательных полях допустимы).

То же можно проверить в [validator.schema.org](https://validator.schema.org).

## 5. Скорость (Lighthouse)

В Chrome: открой страницу → F12 → вкладка Lighthouse → Mode: Navigation, Device: **Mobile** → Analyze. Цель по ТЗ: Performance ≥ 85, SEO ≥ 95 на главной, каталоге и странице объекта.

Результат зависит от фото: загружай снимки не тяжелее 2–3 МБ, сайт сам уменьшает их и отдаёт в WebP.

## 6. Google Ads (Этап 11)

### 6.1. Перед первым объявлением

1. **Реквизиты.** Заполни все поля в `src/config/legal.ts` (там, где `[ЗАПОЛНИТЬ: …]`), закоммить и задеплой. Они видны в подвале каждой страницы, на «Контактах», «О нас», в соглашении, оферте и политике. `npm run dev` напоминает, сколько полей не заполнено.
2. **Боевая база.** На сайте не должно быть объектов `[ТЕСТ]`, объектов без фото и объектов с давно не обновлённой занятостью. Модератор Google открывает посадочную страницу и пару карточек.
3. **«Проверено».** Подключай Pro только после проверки из списка `verifiedChecks` в `src/config/legal.ts`: страница `/ru/verified` обещает это гостям.
4. **Домен.** `NEXT_PUBLIC_SITE_URL` — тот же домен, который будет в объявлениях (`https://…`, без `www`, если сайт открывается без него). Объявление и конечная страница — один домен.

### 6.2. Теги и конверсии

1. [analytics.google.com](https://analytics.google.com) → Администратор → «Создать ресурс» → поток «Веб» с адресом сайта. Скопируй **идентификатор потока** `G-XXXXXXXXXX` → переменная `NEXT_PUBLIC_GA4_ID`.
2. [ads.google.com](https://ads.google.com) → «Цели» → «Конверсии» → «Создать действие-конверсию» → «Сайт» → «Настроить вручную». Создай три действия:
   | Действие                                                                                                                                                                                                                   | Категория                                   | Переменная для метки            |
   | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------- | ------------------------------- |
   | Заявка на бронь                                                                                                                                                                                                            | «Отправка формы для потенциальных клиентов» | `NEXT_PUBLIC_ADS_CONV_LEAD`     |
   | Клик WhatsApp                                                                                                                                                                                                              | «Контакт»                                   | `NEXT_PUBLIC_ADS_CONV_WHATSAPP` |
   | Клик «Позвонить»                                                                                                                                                                                                           | «Контакт»                                   | `NEXT_PUBLIC_ADS_CONV_CALL`     |
   | На шаге «Установка тега» выбери «Установить тег самостоятельно»: Google покажет `send_to: 'AW-123456789/AbCdEfGh'`. `AW-123456789` → `NEXT_PUBLIC_GOOGLE_ADS_ID` (одинаковый для всех), часть после `/` → метка конверсии. |
3. Впиши переменные в Vercel → Settings → Environment Variables и сделай Redeploy.
4. Проверка: [tagassistant.google.com](https://tagassistant.google.com) → адрес сайта → прими cookie → открой объект, нажми WhatsApp и «Позвонить», отправь заявку. В Tag Assistant появятся события `click_whatsapp`, `click_call`, `generate_lead` и конверсии Ads. В Google Ads статус конверсий станет «Активно» в течение суток.
5. Свяжи Google Ads и GA4: Google Ads → «Инструменты» → «Связанные аккаунты» → Google Analytics.

События GA4 без конверсий Ads: `click_instagram`, `owner_request` (форма владельца), `contact_*` (страница «Контакты»).

### 6.3. Cookie и Consent Mode v2

Внизу экрана — уведомление о cookie с кнопками «Принять» и «Отказаться». До выбора и после отказа теги Google работают без cookie (Consent Mode v2 в режиме «advanced»: Google досчитывает конверсии моделированием), а Яндекс Метрика не загружается. «Настройки cookie» в подвале снова открывают уведомление. Выбор хранится в cookie `consent` 180 дней.

### 6.4. Данные для Google Ads и верификации рекламодателя

Всё должно совпадать с подвалом и страницей «Контакты» **буква в букву**:

| Где в Google Ads                        | Что указать                                                                                                     | Поле в `legal.ts`            |
| --------------------------------------- | --------------------------------------------------------------------------------------------------------------- | ---------------------------- |
| Платёжный профиль → тип                 | «Организация» (для ИП и ТОО)                                                                                    | —                            |
| Платёжный профиль → название            | `operator` полностью: «ИП Фамилия Имя Отчество» или «ТОО «Название»»                                            | `operator`                   |
| Платёжный профиль → адрес               | юридический адрес                                                                                               | `address`                    |
| Верификация рекламодателя → юрлицо      | то же название и адрес; документ — талон/уведомление о регистрации ИП или справка о регистрации ТОО (с ИИН/БИН) | `operator`, `bin`, `address` |
| Верификация → ИИН/БИН (налоговый номер) | 12 цифр                                                                                                         | `bin`                        |
| Контактный телефон и email аккаунта     | те же, что на сайте                                                                                             | `phone`, `email`             |
| Отрасль / что рекламируете              | «Каталог загородного отдыха (информационный сервис, бронь у владельцев)»                                        | —                            |
| Конечный URL объявлений                 | `https://<домен>/ru/…` или `/kk/…`                                                                              | `NEXT_PUBLIC_SITE_URL`       |

Валюта аккаунта — KZT, часовой пояс — Алматы (их нельзя поменять после создания).

### 6.5. Правила для объявлений

- Не обещай того, чего нет на странице: «бронь онлайн», «оплата на сайте», «лучшая цена», «№1», «100% свободно». Сайт — каталог; бронь у владельца.
- Цена в объявлении — только «от N ₸», и такой объект должен быть в каталоге.
- Посадочная страница — по теме объявления: «глэмпинг» → `/ru/collections/glempingi`, «с чаном» → `/ru/collections/s-chanom`, общий запрос → `/ru` или `/ru/catalog`.
- Не используй чужие бренды (Booking, Airbnb, Kaspi, названия конкретных глэмпингов) в текстах и ключевых словах без разрешения.
- По закону РК о рекламе реклама распространяется на казахском и русском — делай объявления на обоих языках и веди `/kk` на казахскую версию.

## Переменные

| Переменная                      | Что это                                        |
| ------------------------------- | ---------------------------------------------- |
| `NEXT_PUBLIC_SITE_URL`          | Адрес сайта, `https://…` без `/` в конце       |
| `NEXT_PUBLIC_YANDEX_METRIKA_ID` | Номер счётчика Метрики (только цифры)          |
| `YANDEX_VERIFICATION`           | Значение `content` мета-тега Яндекс Вебмастера |
| `GOOGLE_SITE_VERIFICATION`      | Значение `content` мета-тега Search Console    |
| `NEXT_PUBLIC_GA4_ID`            | Поток Google Analytics 4, `G-…`                |
| `NEXT_PUBLIC_GOOGLE_ADS_ID`     | Тег Google Ads, `AW-…`                         |
| `NEXT_PUBLIC_ADS_CONV_LEAD`     | Метка конверсии «Заявка на бронь»              |
| `NEXT_PUBLIC_ADS_CONV_WHATSAPP` | Метка конверсии «Клик WhatsApp»                |
| `NEXT_PUBLIC_ADS_CONV_CALL`     | Метка конверсии «Клик Позвонить»               |

Без этих переменных сайт работает, просто без счётчика и подтверждения.
