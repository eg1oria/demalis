# Дизайн «демалыс» — для разработчика

Папку `design/` положи в корень проекта. Это **образец**, по которому верстаются страницы. Это не код, который нужно копировать как есть.

## Что внутри

| Файл | Экран | Ширина | Какой этап ТЗ |
|---|---|---|---|
| `screens/mobile-home.png` + `html/mobile-home.html` | Главная, телефон | 390px | Этап 2 (подборки — Этап 6) |
| `screens/mobile-catalog.png` + `html/mobile-catalog.html` | Каталог, телефон | 390px | Этапы 2–3 |
| `screens/mobile-map.png` + `html/mobile-map.html` | Каталог в режиме «Карта» | 390px | Этап 3 |

| `screens/desktop-home.png` + `html/desktop-home.html` | Главная, десктоп | 1440px | Этап 2 |

- **PNG** — как экран должен выглядеть.
- **HTML** — точные размеры, отступы, радиусы и цвета. Открой файл в браузере или прочитай его код. HTML-файлы связаны ссылками, как прототип: главная → каталог → карта → объект.

## Правила

1. **Цвета — только из раздела 7 ТЗ.** В ТЗ те же цвета, что в макете, и они уже разложены по токенам. Если макет и ТЗ расходятся, прав ТЗ.
2. **Не копируй inline-стили из HTML.** Переведи их в Tailwind-классы и переиспользуемые компоненты: `PlaceCard`, `StatusBadge`, `Chip`, `SegmentedControl`, `GuestStepper`, `AvailabilityCalendar`, `MapPin`, `StickyContactBar`, `OwnersBlock`.
3. **Пейзажи на месте фото — заглушки.** В коде используй реальные фото объектов через `next/image` с теми же пропорциями и скруглениями. Если фото нет — показывай такой же спокойный пейзаж-заглушку (один SVG-компонент).
4. **Названия, цены и числа в макете выдуманы.** Бери данные из базы, не хардкодь.
5. **Иконки** — линейные, толщина 1.6–1.8, размер 16–22px. Можно взять похожие из `lucide-react`. Своих иконок для чана, бани и лапы в Lucide нет — перенеси SVG из `html/style-guide.html`.
6. **Шрифты** подключай через `next/font/google` (Literata и Onest с подмножествами `cyrillic`, `cyrillic-ext`, `latin`). Папка `html/fonts/` нужна только для просмотра макета.
7. **Интерактивные состояния, которых не видно на картинках:**
   - чипсы-фильтры: выключен — белый фон и рамка `line`; включён — фон `text`, белый текст;
   - сегмент «Когда» на главной: выбранный — фон `text`, белый текст;
   - переключатель «Только свободные»: включён — трек `accent`, выключен — трек `#CFCBC1`;
   - маркер на карте: выбранный — фон `accent`, белый текст, высота 38px; остальные — белые, высота 32px;
   - карточка со статусом «Занято» — прозрачность 0.6.
8. **Мобильная версия важнее десктопной.** Десктоп — это та же структура, растянутая на сетку из 4 колонок с полями 80px.
