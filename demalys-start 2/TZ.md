## 0. Суть проекта в трёх предложениях

Сайт помогает людям из Алматы быстро найти **загородный отдых на выходные**: глэмпинги, A-frame домики, дома с баней и чаном, зоны отдыха на Капшагае. Главная фишка — **видно, где свободно на ближайшие выходные**: владельцы отмечают занятость через Telegram-бот в пару нажатий. Сайт зарабатывает на владельцах объектов: платные карточки, продвижение и оплата за заявки.

**Рабочее название:** `Демалыс`. Везде используй переменную `SITE_NAME`, а не зашитый текст: название ещё может поменяться.

**Главное ограничение: бюджет почти нулевой.** Используй только бесплатные тарифы. Любой платный сервис — только после вопроса владельцу проекта.

## 3. Технологии (уже выбраны, не менять)

| Что | Решение | Почему |
|---|---|---|
| Фреймворк | **Next.js** (App Router) + **TypeScript** | SEO из коробки (серверный рендер), один проект для сайта, API и бота |
| Стили | **Tailwind CSS** | Быстро, без отдельного дизайна |
| База, авторизация, файлы | **Supabase** (бесплатный тариф): Postgres + Auth + Storage | Бесплатно, всё в одном месте |
| Карта | **Leaflet** + тайлы OpenStreetMap | Бесплатно, без ключей |
| Переводы | **next-intl**, адреса `/ru/...` и `/kk/...` | Два языка с правильным SEO |
| Telegram-бот | **grammY**, работает через webhook в API-маршруте Next.js | Не нужен отдельный сервер |
| Хостинг | **Vercel** (бесплатный тариф) | Бесплатно для старта |
| Аналитика | **Яндекс Метрика** + **Google Search Console** + **Яндекс Вебмастер** | На Яндекс приходится около трети поиска в Казахстане |

## 4. Словарь (чтобы понимать одинаково)

- **Объект** — одно место отдыха: глэмпинг, дом, зона отдыха. В базе — таблица `places`.
- **Владелец** — человек, который управляет объектом. Общается с системой через Telegram-бот.
- **Заявка (лид)** — запрос посетителя на бронь через форму на сайте.
- **Клик WhatsApp** — нажатие кнопки «Написать в WhatsApp». Считается отдельно от заявок.
- **Ближайшие выходные** — ночи с пятницы на субботу и с субботы на воскресенье.
  - Часовой пояс всегда **Asia/Almaty**.
  - Если сегодня пн–пт — это ближайшие пятница и суббота.
  - Если сегодня суббота — это сегодняшняя ночь (суббота).
  - Если сегодня воскресенье — это следующие пятница и суббота.
  - Логику вынеси в одну функцию `getUpcomingWeekend(now)` и покрой тестами.
- **Свободно на выходные** — у объекта на ночь **субботы** статус `free` или `limited`, и данные обновлены **не позже 7 дней назад**.
- **Устаревшие данные** — занятость обновлялась больше 7 дней назад. Тогда вместо «Свободно» показываем «Уточняйте наличие».

## 6. Страницы сайта

| Адрес | Что на странице |
|---|---|
| `/[locale]` | Главная: заголовок, поиск (ближайшие выходные / следующие / выбрать дату, число гостей), быстрые фильтры-чипсы, 3–4 подборки, блок «Для владельцев» |
| `/[locale]/catalog` | Каталог: фильтры, список карточек, переключатель «Список / Карта». Все фильтры хранятся в адресе (`?chan=1&drive=60`), чтобы ссылкой можно было поделиться |
| `/[locale]/place/[slug]` | Объект: галерея, цена, удобства, календарь на 30 дней, карта, кнопка WhatsApp, форма заявки, похожие объекты |
| `/[locale]/collections/[slug]` | SEO-подборки: «с чаном», «с животными», «до часа езды», «Капшагай», «глэмпинги», «зимой» и т.д. |
| `/[locale]/owners` | Лендинг для владельцев: зачем размещаться, как работает бот, тарифы (на Этапе 7 — без оплаты), форма «Добавить объект» |
| `/[locale]/privacy` | Политика конфиденциальности (шаблон, владелец проекта проверит) |
| `/admin/...` | Админка, только для админов (вход по email-ссылке, список админов в `ADMIN_EMAILS`) |

### Фильтры каталога
- **Даты:** «Эти выходные», «Следующие выходные», конкретная дата.
- **Время в пути:** до 30 мин / до 1 ч / до 2 ч / любое.
- **Гостей:** число → `capacity_max >= N`.
- **Цена за ночь:** до 30 тыс. / 30–60 тыс. / 60–100 тыс. / выше.
- **Удобства (чекбоксы):** баня, чан, бассейн, можно с животными, кухня, зимой.
- **Тип** и **направление**.
- **Сортировка:** рекомендуемые (по умолчанию) / сначала дешевле / ближе к Алматы.

### Карточка объекта в списке
Фото, название, тип, время в пути, «от X ₸», 3 главных удобства иконками и плашка занятости на выбранные даты: 🟢 Свободно / 🟡 Мало мест / 🔴 Занято / ⚪ Уточняйте наличие.

### Кнопка WhatsApp
- Ведёт на `/api/go/whatsapp/[placeId]?dates=...&guests=...`. Этот маршрут записывает событие `whatsapp_click` и перенаправляет на `https://wa.me/<номер>?text=<текст>`.
- Готовый текст: «Здравствуйте! Пишу с сайта {SITE_NAME}. Интересует {название} на {даты}, нас {N} человек. Есть свободные места?»

- Без анимаций ради анимаций.

- `npm run build`, `npm run lint`, `npm test` проходят без ошибок.

### Этап 1 — База данных и админка
**Задачи**
- Миграции для всех таблиц из раздела 5 с RLS-политиками.
- Вход в админку по email-ссылке (Supabase Auth). Доступ только для email из `ADMIN_EMAILS`.
- Админка:
  - список объектов с поиском и фильтром по статусу;
  - создание и редактирование объекта со всеми полями, загрузкой фото в Supabase Storage и автоматическим slug из названия (транслитерация);
  - ручное редактирование занятости на 60 дней вперёд (сетка дат, клик переключает статус);
  - **импорт объектов из CSV** (шаблон `places_template.csv` положи в репозиторий), с предпросмотром и понятными ошибками по строкам.
- Скрипт `seed`: 12 тестовых объектов с пометкой `[ТЕСТ]` в названии и случайной занятостью.

**Готово, если**
- Админ может войти, создать объект с фото, опубликовать его и отметить даты.
- Не-админ на `/admin` получает отказ.
- CSV из 10 строк импортируется. Строка с неверным телефоном показывает ошибку и не ломает остальные строки.
- Анонимный запрос к базе не видит черновики.

### Этап 2 — Публичный каталог и страница объекта
**Задачи**
- Главная (без подборок, их добавишь на Этапе 6), каталог и страница объекта по разделу 6.
- Все фильтры, кроме дат, работают и сохраняются в адресе.
- Страница объекта: галерея (свайп на телефоне), удобства, цена, описание, контакты, кнопка WhatsApp (пока прямая ссылка без учёта клика).
- Если `name_kk` или `description_kk` пустые — показывай русский текст.
- Если `photos_permission = false` — вместо фото показывай аккуратную заглушку.
- Страница 404 для несуществующих slug.

**Готово, если**
- На телефоне (375px) каталог и страница объекта выглядят аккуратно, нет горизонтальной прокрутки.
- Фильтр «чан + до 1 ч + 6 гостей» показывает правильные объекты. Проверь на тестовых данных и опиши в отчёте, какие объекты должны попасть в выдачу.
- Ссылку с фильтрами можно открыть в новой вкладке — фильтры сохраняются.

### Этап 3 — Карта и занятость («Свободно на выходные»)
**Задачи**
- Переключатель «Список / Карта» в каталоге (Leaflet). Маркеры с ценой, при нажатии — мини-карточка.
- Фильтр дат: «Эти выходные», «Следующие выходные», конкретная дата. Логика — раздел 4.
- Плашки занятости на карточках и в списке.
- Календарь на 30 дней на странице объекта с цветами статусов и подписью «обновлено N дней назад».
- Правило устаревших данных: больше 7 дней без обновления → «Уточняйте наличие».
- Тумблер «Показывать только свободные» — **включён по умолчанию**, когда выбраны даты.

**Готово, если**
- Тесты на логику статусов (свободно / мало мест / занято / устарело / неизвестно).
- В админке меняешь статус субботы на «занято» — объект пропадает из фильтра «Эти выходные».

### Этап 4 — Заявки и учёт кликов
**Задачи**
- Форма заявки на странице объекта: имя, телефон, даты (подставлены из фильтра), гостей, комментарий.
- Защита от спама: скрытое поле-ловушка и не больше 3 заявок с одного IP за час. IP не сохраняй, используй только для лимита.
- После отправки — экран «Заявка отправлена, владелец свяжется с вами» и кнопка WhatsApp как запасной вариант.
- Уведомление о каждой новой заявке в Telegram-чат админа (переменная `ADMIN_TELEGRAM_CHAT_ID`).
- Маршрут `/api/go/whatsapp/[placeId]` из раздела 6 с записью клика. То же для телефона и Instagram.
- Запись `view` при открытии страницы объекта (не чаще раза в 30 минут с одного браузера — через cookie).
- В админке: список заявок со сменой статуса и простая статистика по каждому объекту за 7 и 30 дней: просмотры, клики WhatsApp, заявки.

**Готово, если**
- Отправленная заявка появляется в админке, а в Telegram админа приходит сообщение.
- Клик WhatsApp открывает WhatsApp с готовым текстом и виден в статистике.
- Четвёртая заявка за час с одного IP отклоняется с понятным сообщением.

### Этап 5 — Telegram-бот для владельцев
**Задачи**
- Бот на grammY через webhook `/api/telegram/webhook` с проверкой секретного токена.
- **Привязка:** в админке у владельца кнопка «Создать код привязки». Владелец пишет боту `/start КОД` — его `telegram_chat_id` сохраняется, код становится недействительным.
- **Меню владельца** (кнопки, а не команды):
  - **«Отметить даты»** — выбор объекта (если их несколько) → кнопки на 14 дней вперёд вида `Сб 04.10 🟢`. Нажатие переключает статус по кругу 🟢 → 🟡 → 🔴 → 🟢. Кнопка «Готово» сохраняет.
  - **«Всё свободно на выходные» / «Всё занято на выходные»** — быстрые кнопки.
  - **«Мои заявки»** — последние 10 заявок.
  - **«Статистика»** — просмотры, клики и заявки за 7 дней.
- **Новая заявка** приходит владельцу в бот с кнопками «Связался ✅» и «Не дозвонился». Нажатия меняют статус заявки.
- **Напоминание** каждый четверг в 12:00 по Алматы: «Обновите занятость на выходные» с кнопкой. Используй Vercel Cron.
- Все тексты бота — на русском и казахском. Язык выбирается при первом `/start`.

**Готово, если**
- Путь «привязка → отметить субботу занятой → на сайте объект пропал из "Эти выходные"» работает за 1 минуту.
- Заявка с сайта приходит владельцу в бот.
- Чужой человек, написавший боту без кода, видит приветствие и не получает доступа ни к чему.

### Этап 6 — SEO и подборки
**Задачи**
- Страницы подборок `/collections/[slug]`. Каждая — это сохранённый набор фильтров + заголовок + вводный текст (ru/kk), который админ редактирует в админке. Создай стартовые 10 подборок: с чаном, с баней, с животными, до часа езды, Капшагай, глэмпинги, A-frame, для большой компании (10+), зимой, недорого (до 30 тыс.).
- Мета-теги title/description для всех страниц, Open Graph с фото объекта.
- `sitemap.xml` и `robots.txt`, hreflang между `/ru` и `/kk`.
- Микроразметка JSON-LD `LodgingBusiness` на странице объекта и `BreadcrumbList`.
- Подключи Яндекс Метрику (ID из переменной окружения) и подготовь инструкцию для владельца проекта: как добавить сайт в Google Search Console и Яндекс Вебмастер.
- Проверь скорость: Lighthouse на мобильном для главной, каталога и объекта. Результаты — в отчёт.

**Готово, если**
- Подборки открываются, их видно в sitemap.
- Валидатор структурированных данных Google не показывает ошибок на странице объекта.
- Lighthouse Performance ≥ 85 (мобильный) на трёх ключевых страницах, SEO ≥ 95.

### Этап 8 — Монетизация (ручная, без платёжной интеграции)
Сначала деньги принимаются **вручную** (счёт в Kaspi от ИП). Интеграцию с платёжками не делай.

**Задачи**
- В админке у объекта: тариф `free/pro`, дата окончания Pro, продвижение до даты (`featured_until`), отметка «оплачено» с суммой и датой (новая таблица `payments`: place_id, amount, kind, paid_at, comment).
- **Pro даёт:** до 20 фото (free — 5), видео, календарь занятости на сайте (у free статус не показывается — только «Уточняйте наличие»), плашку «Проверено» и статистику в боте.
- **Продвижение:** такие объекты показываются первыми в «рекомендуемых» с пометкой «Реклама» и максимум 2 в первом экране каталога.
- **Учёт платных заявок:** у заявки флаг `billable`. Отчёт в админке — сколько платных заявок у объекта за месяц.
- Автоматическое напоминание владельцу в бот за 5 дней до окончания Pro.
- Перед началом этапа напомни владельцу проекта про условия бесплатного тарифа Vercel (раздел 3).

**Готово, если**
- Админ переводит объект в Pro — на сайте сразу появляется календарь и плашка.
- Когда срок Pro истёк, объект автоматически возвращается к free.

## 11. Для владельца проекта (не для агента)

Пока агент работает, параллельно делайте ручную часть — без неё сайт будет пустым:

1. **Недели 1–2:** соберите таблицу из 100 объектов вокруг Алматы (название, телефон, Instagram, направление, цена от, удобства). Используйте шаблон CSV из Этапа 1.
2. **Позвоните или напишите 30 владельцам.** Спросите: сколько им пишут в сезон, сколько заявок теряется, платят ли за рекламу в Instagram и сколько. Предложите бесплатное размещение и попросите разрешение на фото.
3. **К Этапу 5** подключите первых 10 владельцев к боту лично и посмотрите, где они путаются. Упрощайте.
4. **Контент:** 3–5 коротких видео в неделю в TikTok и Reels со ссылкой на сайт («Куда поехать из Алматы до 30 тыс. ₸», «Дома с чаном до часа езды»).
5. **До Этапа 8:** откройте ИП (можно через приложение Kaspi) и уточните актуальный налоговый режим.
6. **Проверьте все казахские тексты** с пометкой `TODO: проверить носителю`.
