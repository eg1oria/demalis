# Логотип «демалыс»

Знак — домик A-frame на ножках, который одновременно читается как кириллическая **«д»** — первая буква названия. Дверь-щель, золотое солнце у конька. Рядом — слово «демалыс» шрифтом Unbounded 500, строчными.

| Файл | Для чего |
|---|---|
| `mark.svg` | Знак на светлом фоне |
| `mark-light.svg` | Знак на тёмном фоне |
| `icon.svg` | Знак на тёмной плитке (как фавикон сайта) |
| `logo.png`, `logo-dark.png` | Знак + слово, 1200×400 — документы, презентации, соцсети |
| `avatar-512.png` | Аватарка Telegram-бота, Instagram, WhatsApp Business |
| `avatar-light-512.png` | То же на светлом фоне |

Цвета: тёмный `#111111`, светлый `#FAFAF8`, солнце `#D9A441`. Солнце — единственное цветное пятно, не перекрашивать.

В коде фигуры знака лежат в `src/config/brand.ts` (шапка, подвал, админка, заставка `/api/og`). Фавиконы — `src/app/icon.svg` и `src/app/apple-icon.png`. Если меняешь знак — обнови все места.
