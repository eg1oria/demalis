## Этап 0 — подготовка проекта

Сделано:

- Next.js 16 (App Router) + TypeScript + Tailwind CSS 4 + ESLint + Prettier.
- next-intl: `/ru` (по умолчанию) и `/kk`, `/` перенаправляет на `/ru`, переключатель языка в шапке.
- Заглушка главной с названием из `SITE_NAME` (`NEXT_PUBLIC_SITE_NAME`).
- Цвета из раздела 7.6 ТЗ заведены CSS-переменными в `globals.css` и подключены в Tailwind; шрифты Onest и Literata через `next/font`.
- `getUpcomingWeekend(now)` (`src/lib/weekend.ts`) + 14 тестов Vitest: все 7 дней недели, переход через месяц и год, граница суток по Asia/Almaty.
- `.env.example`, `README.md`, `IDEAS.md`, инструкция `docs/SETUP.md`.

## Этап 1 — база данных и админка

Сделано:

- Миграция `supabase/migrations/20260927000000_init.sql`: таблицы `places`, `availability`, `owners`, `leads`, `events`, все enum из ТЗ, триггеры `updated_at`, проверки формата (телефон `+77XXXXXXXXX`, slug).
- RLS: аноним видит только опубликованные объекты и их занятость; `owners`, `leads`, `events` закрыты. Запись — только серверный код с секретным ключом после проверки админа.
- Storage: бакет `place-photos` (публичное чтение, JPG/PNG/WebP до 10 МБ). Загрузка — по подписанной ссылке, которую выдаёт сервер только админу.
- Вход в `/admin` по ссылке на email (Supabase Auth). Ссылку получают только адреса из `ADMIN_EMAILS`; вошедший не-админ видит «Нет доступа».
- Админка: список с поиском и фильтром по статусу; создание/редактирование со всеми полями, фото и автоматическим slug (транслитерация рус/каз); сетка занятости на 60 дней; импорт CSV с предпросмотром и ошибками по строкам.
- `public/places_template.csv` — шаблон, `docs/examples/import-10-rows.csv` — пример на 10 строк (строка 7 с неверным телефоном).
- `npm run seed` — 12 объектов `[ТЕСТ]` (10 опубликованы, 1 черновик, 1 скрыт) со случайной занятостью.
- Тесты: телефон, slug, проверка полей объекта, список админов (всего 50).

Для Этапа 2: фильтр «чан + до 1 ч + 6 гостей» на тестовых данных должен найти ровно 3 объекта — «Банный комплекс «Каскелен»», «Шале в горах», «Юрта-глэмпинг «Талгар»» (черновик с чаном не показывается).

## Этап 2 — публичный каталог и страница объекта

Сделано:

- Главная: заголовок, поиск («Эти выходные / Следующие / Своя дата», гости со счётчиком вариантов), быстрые чипсы, блок «Для владельцев». Подборки — Этап 6.
- Каталог `/catalog`: все фильтры из раздела 6, кроме дат, хранятся в адресе (`?chan=1&drive=60&guests=6`), чипсы, панель «Все фильтры», сортировка, «Показать ещё».
- Страница объекта `/place/[slug]`: галерея со свайпом, цена, удобства, описание, контакты (WhatsApp, звонок, Instagram, видео), адрес и ссылка на карту, похожие объекты, нижняя панель с WhatsApp.
- WhatsApp — прямая ссылка `wa.me` с текстом из ТЗ; гости и даты берутся из фильтров каталога.
- Пустые `name_kk` / `description_kk` → русский текст; `photos_permission = false` → пейзаж-заглушка; неизвестный slug → 404.
- Компоненты по design/README: PlaceCard, Chip, SegmentedControl, GuestStepper, OwnersBlock, пейзаж-заглушка, иконки из макета.
- Тесты: фильтры и адрес, даты «эти/следующие выходные», перевод полей, WhatsApp-ссылка (всего 70).

Проверка фильтра «чан + до 1 ч + 6 гостей» (`/ru/catalog?chan=1&drive=60&guests=6`): 3 тестовых объекта — «Банный комплекс «Каскелен»», «Шале в горах», «Юрта-глэмпинг «Талгар»» + созданный вручную на Этапе 1 «Дом «Проверка» у Медеу» (чан, 40 мин, 6 гостей). Черновик с чаном не показывается.

## Этап 3 — карта и занятость

Сделано:

- Логика статусов `src/lib/availability.ts`: свободно / мало мест / занято / устарело (>7 дней без обновления) / неизвестно. Для выходных решает ночь субботы, для конкретной даты — она сама. 10 тестов.
- Миграция `20260928000000_availability_freshness.sql`: представление `place_availability_updates` (последнее обновление занятости объекта), с RLS.
- Каталог: фильтр дат («Эти выходные», «Следующие», своя дата) в панели фильтров, тумблер «Только свободные» (включён по умолчанию при выбранных датах, выключение — `?all=1`), плашки статуса на карточках, «Занято» — прозрачность 0.6.
- «Список / Карта» (`?view=map`): Leaflet + тайлы OpenStreetMap, маркеры с ценой и точкой статуса, выбранный — accent, мини-карточка по нажатию.
- Страница объекта: блок «Свободно в эту субботу» (или на выбранную дату), календарь на 30 дней со статусами, подпись «обновлено N дней назад», выбранные ночи обведены; плашки у похожих объектов.
- Главная: «Показать N вариантов» считает свободных на выбранные даты (`/api/catalog/count`).

Проверено: в админке суббота «[ТЕСТ] Шале в горах» → «Занято» — объект пропал из `?when=this` (5 → 4), вернул обратно.

## Этап 4 — заявки и учёт кликов

Сделано:

- Миграция `20260929000000_leads_and_stats.sql`: таблица лимита `lead_rate_limits`, функции `hit_lead_rate_limit` (не больше 3 заявок с IP за час, атомарно) и `place_stats` (просмотры, клики WhatsApp, заявки за 7 и 30 дней). Обе доступны только серверному ключу.
- Форма заявки на странице объекта (`#lead`, кнопка «Заявка» в нижней панели): имя, телефон, заезд/выезд (из фильтра каталога), гости, комментарий. Ошибки по полям, введённое при ошибке не теряется.
- Защита от спама: скрытое поле-ловушка (бот видит «отправлено», в базу ничего не пишется) и лимит 3 заявки в час с одного IP. IP не хранится: в таблицу пишется HMAC-хэш IP с секретным ключом, записи старше часа удаляются.
- После отправки — «Заявка отправлена, владелец свяжется с вами» и кнопка WhatsApp.
- Уведомление о заявке в Telegram-чат админа (`ADMIN_TELEGRAM_CHAT_ID`) — после ответа посетителю, ошибка Telegram не ломает заявку. Инструкция — `docs/SETUP.md`, раздел 2а.
- `/api/go/whatsapp/[placeId]?dates=…&guests=…` — пишет `whatsapp_click` и перенаправляет на `wa.me` с текстом из ТЗ (на языке страницы). То же для Instagram (`/api/go/instagram/…`).
- Звонок: ссылка остаётся `tel:` (перенаправление на `tel:` работает не во всех браузерах), клик уходит фоном на `/api/go/phone/…`.
- Просмотр (`view`) пишется из браузера после открытия страницы, не чаще раза в 30 минут — cookie на 30 минут, привязанная только к адресу `/api/view/<id>`.
- Роботы (Googlebot, YandexBot, превью ссылок в WhatsApp/Telegram) не считаются ни кликами, ни просмотрами.
- Админка: «Заявки» (`/admin/leads`) — список с фильтром и сменой статуса; «Статистика» (`/admin/stats`) — по каждому объекту за 7 / 30 дней.
- Тесты: проверка заявки, текст для Telegram, ссылки `/api/go`, IP/хэш/роботы (всего 107).

Проверено на локальной базе (Postgres + PostgREST): 3 заявки с одного IP проходят, 4-я — «С вашего устройства уже отправлено 3 заявки за последний час…»; бот с заполненной ловушкой в базу не попал; клик WhatsApp перенаправляет с готовым текстом и появляется в статистике; повторные просмотры в течение 30 минут не считаются; смена статуса заявки сохраняется. Отправку в Telegram проверить здесь не удалось — песочница не пускает на api.telegram.org; проверить после ввода ключей.

## Этап 5 — Telegram-бот для владельцев

Сделано:

- Бот на grammY, webhook `/api/telegram/webhook`: без правильного секрета (`TELEGRAM_WEBHOOK_SECRET`) — 401. Работает только в личных сообщениях.
- Миграция `20260930000000_owner_bot.sql`: язык бота у владельца, формат кода привязки.
- Админка «Владельцы»: список (подключён ли бот), создание и правка, «Создать код привязки» (одноразовый, 8 символов, со ссылкой `t.me/бот?start=КОД`), «Отвязать бота».
- Привязка: `/start КОД` → чат сохраняется, код стирается. Затем выбор языка (русский / казахский) и меню.
- Меню кнопками: «Отметить даты» (выбор объекта, 14 дней вида `Сб 03.10 🟢`, нажатие 🟢 → 🟡 → 🔴 → 🟢, «Готово» сохраняет; незаконченная правка хранится в самих кнопках), «Всё свободно / Всё занято на выходные», «Мои заявки» (10 последних), «Статистика» (просмотры, клики WhatsApp, заявки за 7 дней).
- Новая заявка с сайта приходит владельцу с кнопками «Связался ✅» (→ «подтверждена») и «Не дозвонился» (→ «не дозвонились»); после отправки статус — «отправлена владельцу».
- Напоминание по четвергам в 12:00 по Алматы: Vercel Cron (`vercel.json`) → `/api/cron/reminder` (защищён `CRON_SECRET`), с кнопкой «Отметить даты».
- Чужой человек без кода видит приветствие на двух языках и больше ничего; чужие кнопки (заявки, объекты) не срабатывают.
- `npm run bot:webhook` и инструкция в `docs/SETUP.md`, раздел 2б.
- Тесты: данные кнопок (≤ 64 байт, разбор мусора), даты и подписи кнопок, тексты ru/kk, сообщения бота, код привязки (всего 141).

Проверено на локальной базе и поддельном сервере Telegram (записывает всё, что шлёт бот): привязка по коду → суббота отмечена 🔴 → объект пропал из «Эти выходные» → «Всё свободно на выходные» вернуло его; повторный код не работает; заявка с сайта пришла владельцу и админу, кнопки меняют статус; напоминание отправляется только с верным секретом; меню на казахском работает. Живой Telegram здесь недоступен — проверить на реальном боте после настройки.

## Известные проблемы

- Казахские тексты переведены не носителем — помечены `// TODO: проверить носителю`.
- Файлы переводов — `.ts`, а не `.json`: в JSON нельзя писать комментарии, а ТЗ требует помечать непроверенные переводы.
- Next.js 16: вместо `middleware.ts` используется `src/proxy.ts` (новое имя того же механизма).
- Админка только на русском: в ТЗ адрес `/admin/...` без языка.
- Фото, загруженные в форму, но не сохранённые кнопкой «Сохранить», остаются в Storage без объекта. Пока не чистим.
- Бакет фото публичный: фото черновиков доступны по прямой ссылке (адрес случайный, нигде не опубликован).
- Встроенная почта облачного Supabase — несколько писем в час; для 1–2 админов хватает.
- `/owners` — заглушка, лендинг будет на Этапе 7.
- Для сборки на Vercel теперь нужны ключи Supabase (главная берёт число вариантов из базы).
- Фильтр по датам считается в коде сервера по всем подходящим объектам (до 1000). При росте базы — перенести в SQL.
- Лимит заявок считается по IP: все устройства за одним IP (офисная сеть, иногда мобильный оператор) делят 3 заявки в час.
- Клики и просмотры можно накрутить прямыми запросами к `/api/go/…` и `/api/view/…` — защиты от накрутки в ТЗ нет.
- Отправка в Telegram не повторяется при сбое — заявка всё равно есть в админке.
- Язык бота выбирается только при первом `/start`; сменить его сейчас может админ (отвязать и привязать заново).
- Если владелец долго не нажимает «Готово», кнопки дат остаются от дня открытия; прошедшие дни при сохранении пропускаются.
- Бесплатный Vercel Cron запускается в течение часа: напоминание придёт между 12:00 и 12:59.
- Тайлы OpenStreetMap бесплатны, но с правилами использования (без массовой нагрузки). При большом трафике — перейти на другой бесплатный/дешёвый источник тайлов (спросить владельца).
